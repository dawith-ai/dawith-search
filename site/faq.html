설치·업데이트

설치할 때 ‘Windows의 PC 보호’ 경고가 떠요

설치파일에 코드 서명 인증서가 없어서 Windows SmartScreen이 경고를 띄웁니다. 공식 다운로드 페이지나 GitHub 릴리스에서 받은 파일이 맞다면 아래처럼 진행하세요.

  1. 경고 창에서 추가 정보를 누릅니다.
  2. 아래에 생긴 실행 버튼을 누릅니다.

받은 파일이 원본과 같은지 확인하려면 다운로드 페이지의 SHA256 값과 비교해 보세요.

macOS에서 앱이 열리지 않아요

처음 실행할 때 Gatekeeper 경고가 나올 수 있습니다. Finder에서 Dawith Search 앱을 우클릭 → 열기로 실행하면 다음부터는 그냥 열립니다.

Everything을 따로 설치해야 하나요?

아니요. Dawith Search는 자체 색인(Dawith 색인)으로 검색합니다. 파일 이름·폴더·크기·날짜를 담은 목록을 메모리에 올려 두고 CPU 코어를 모두 써서 찾기 때문에, 파일이 46만 개쯤 있는 PC에서도 한 번 검색하는 데 0.01~0.05초 정도 걸립니다.

1.3.0부터는 Everything을 기본으로 쓰지 않으므로, 설치 여부와 관계없이 같은 방식으로 검색합니다. 꼭 Everything과 연결해 쓰고 싶다면 ~/.dawith-search/config.json에 "useEverything": true를 넣으면 됩니다. 아직 설정 화면에는 이 항목이 없습니다.

처음 실행하면 왜 기다려야 하나요?

처음 실행할 때 이 PC의 파일 목록을 만들기 때문입니다. C 드라이브 기준으로 1분 정도 걸리고, 네트워크 공유폴더를 추가했다면 더 걸립니다. 목록을 만드는 동안에도 이미 찾은 파일부터 검색됩니다. 진행 상황은 첫 실행 안내 창과 제목 표시줄의 진행 막대(%)로 볼 수 있습니다.

만든 목록은 이 PC에 저장해 두므로, 다음부터는 앱을 켜자마자 검색할 수 있습니다.

새 버전은 어떻게 받나요?

앱에서 바로 업데이트합니다. 새 버전이 나오면 상단에 vX.Y.Z 업데이트 버튼이 보이고, 누르면 설치파일을 받아 SHA-256 값을 확인한 뒤 진행 창을 띄워 설치하고 앱을 다시 시작합니다.

macOS도 최신 버전을 쓸 수 있나요?

아직은 아닙니다. macOS용 최신 버전은 준비 중이며, 지금은 1.1.8 Universal DMG(Apple Silicon·Intel 공용)를 사용해 주세요.

검색

검색 결과에 파일이 안 나와요

아래 순서로 확인해 보세요.

  1. 필터 탭이 모두인지 확인합니다. ‘문서’나 ‘사진’ 탭이 켜져 있으면 다른 종류는 빠집니다.
  2. 검색어를 줄여 봅니다. 공백은 AND라서 단어가 많을수록 결과가 줄어듭니다. 이름 일부만 넣어도 됩니다.
  3. 파일이 공유폴더·NAS·외장 디스크에 있다면 먼저 검색 위치로 추가해야 합니다. 로컬 드라이브만 자동으로 검색합니다. (공유폴더 추가 방법)
  4. 이미 추가한 위치라면 설정 → 검색 위치에서 추가한 위치 다시 읽기를 눌러 새 파일을 반영합니다.
  5. 본문 속 단어로 찾는 중이라면 content:를 붙였는지 확인하세요. 예: content:계약서

검색이 느려요

처음 실행한 직후라면 파일 목록을 만드는 중일 수 있습니다. 제목 표시줄의 진행 막대가 사라질 때까지 기다려 주세요. (처음 실행할 때 기다리는 이유)

공유폴더에 size:나 dm: 조건을 걸면 파일 정보를 네트워크로 읽어야 해서 몇 초 걸릴 수 있습니다.

새로 만든 파일이 바로 안 나와요

1.3.1부터는 파일을 만들거나 지우거나 이름을 바꾸면 1초 안팎으로 검색 결과에 반영됩니다. 그래도 안 보이면 그 파일이 검색 위치 밖에 있거나 제외 폴더(예: AppData, node_modules) 안에 있는지 확인하세요.

공유폴더에 생긴 파일은 설정 → 검색 위치에서 추가한 위치 다시 읽기를 눌러도 됩니다.

여러 조건을 한 번에 걸 수 있나요?

네. Everything과 비슷한 문법을 씁니다. 공백은 AND, |는 OR, !나 -는 제외입니다.

예: 보고서 ext:hwp,pdf dm:lastweek → 지난주에 수정한 HWP·PDF 중 이름에 ‘보고서’가 들어간 파일. 전체 목록은 도움말의 검색 문법에 있습니다.

문장으로 검색할 수 있나요?

검색창 옆 자연어 검색을 켜면 “어제 작성한 엑셀 파일”, “지난주 100GB 이상 동영상” 같은 문장을 검색 문법으로 바꿔 줍니다. 자세한 내용은 도움말을 보세요.

검색 범위·공유폴더

처음에는 어디까지 검색하나요?

Windows에서는 이 PC의 로컬 드라이브 전체를 자동으로 검색합니다. 바탕화면·문서 폴더를 하나씩 지정할 필요가 없습니다. 공유폴더, 연결된 네트워크 드라이브, 외장 디스크는 직접 추가한 곳만 검색합니다.

공유폴더(NAS) 파일도 찾을 수 있나요?

네. 검색 위치로 추가하면 로컬 파일과 함께 검색됩니다.

  1. 설정을 열고 검색 위치에서 폴더·공유 위치 추가를 고릅니다.
  2. 탐색기로 고르려면 폴더·드라이브 선택, 경로를 아는 경우에는 공유폴더 경로 입력을 누릅니다.
  3. \\서버\공유폴더 형식으로 입력하고 연결 확인 및 추가를 누르면 접속이 되는지 확인한 뒤 추가합니다.

공유폴더 권한이 있는 Windows 계정으로 앱을 실행해야 합니다. 네트워크 드라이브(Z: 등)보다 \\서버\공유폴더 경로를 권장합니다.

공유폴더 결과에 크기·날짜가 ‘—’로 나와요

정상입니다. 공유폴더 파일마다 크기와 날짜를 네트워크로 읽으면 검색이 크게 느려지기 때문에 목록에서는 ‘—’로 표시합니다.

size:, dm: 필터는 공유폴더에서도 동작합니다. 다만 이때는 정보를 실제로 읽어야 해서 몇 초 걸릴 수 있습니다.

추가한 공유폴더 파일이 안 보여요

  1. 탐색기에서 그 경로가 열리는지 먼저 확인합니다. 연결이 끊겼다면 다시 연결합니다.
  2. 설정 → 검색 위치에서 추가한 위치 다시 읽기를 누릅니다.
  3. 그래도 안 되면 해당 위치를 제거한 뒤 \\서버\공유폴더 경로로 다시 추가해 보세요.

한글(HWP)·문서

HWP 본문도 검색되나요?

네(Windows 1.2.0부터). 일반 HWP 문서는 본문 속 단어로 찾을 수 있고, 미리보기로 내용도 볼 수 있습니다. 본문을 검색할 때는 content:를 붙이세요.

예: content:운영위원회 ext:hwp

보안(DRM) 한글 문서는요?

DRMONE 같은 문서 보안이 걸린 HWP는 본문을 읽을 수 없습니다. 대신 제목(파일 이름)으로는 계속 검색되고, 미리보기에는 본문을 읽을 수 없다는 안내가 나옵니다.

본문까지 검색해야 한다면, 기관 규정상 허용되는 경우에 한해 한글에서 문서를 열고 보안이 없는 사본으로 저장한 뒤 그 사본을 검색하세요.

문서 속 직인/이미지 글자도 찾나요?

아니요. 문서에 그림으로 들어간 글자(직인, 스캔한 서명, 캡처 이미지 등)는 문자 인식(OCR)을 하지 않으므로 검색되지 않습니다. 문서에 텍스트로 입력된 내용만 찾을 수 있습니다.

PDF로 바꾸거나 합칠 수 있나요?

검색 결과에서 파일을 우클릭하고 파일 변환을 고르면 PNG·JPG를 PDF로 바꾸거나 PDF를 합치고 나눌 수 있습니다. 원본은 그대로 둡니다. Office·한글 문서는 PC에 설치된 Word·Excel·PowerPoint·한글로 PDF를 만듭니다. 해당 프로그램이 없거나, 암호 또는 보안(DRM)이 걸린 파일이면 변환하지 않고 이유를 알려 줍니다.

개인정보·보안

검색어나 파일 목록이 외부로 전송되나요?

아니요. 검색, 색인, 파일 목록은 모두 이 PC 안에서 처리합니다. 파일 내용을 외부 서버나 외부 AI로 보내지 않습니다.

자연어 검색은 외부 AI를 쓰나요?

쓰지 않습니다. 자연어 검색은 인터넷 연결 없이 앱 안의 규칙으로 문장을 검색식으로 바꿉니다.

결과에서 파일을 지우면 바로 사라지나요?

아니요. 결과에서 Delete를 누르거나 우클릭 → 삭제를 고르면 파일을 휴지통으로 보냅니다. 실수로 지웠다면 휴지통에서 되살릴 수 있습니다.

문제 해결

검색할 때 검은 창이 잠깐 떠요

1.2.0 이전 Windows 버전에서 생기던 문제로, 1.2.0에서 고쳤습니다. 다운로드 페이지에서 최신 설치파일을 받아 주세요.

오류는 어디에 알리나요?

GitHub 이슈에 남겨 주세요. 사용 중인 운영체제와 앱 버전, 어떤 검색어에서 문제가 생겼는지, 공유폴더라면 경로 형식(\\서버\공유폴더 또는 Z: 드라이브)을 함께 적어 주시면 빨리 확인할 수 있습니다. 파일 이름이나 경로에 개인정보가 있다면 가려 주세요.
