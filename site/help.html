Dawith Search 도움말

Windows 1.2.0 기준 사용 안내입니다. 주제를 골라 바로 이동하세요. 짧은 질문과 답은 자주 묻는 질문에 정리해 두었습니다.

  1. 설치Windows·macOS 설치와 첫 실행 경고
  2. 첫 실행과 검색 범위로컬 드라이브 자동 검색, 검색 엔진
  3. 검색 문법AND·OR·NOT, ext:, size:, dm:, content:
  4. 자연어 검색문장을 검색식으로 바꾸기
  5. 필터 탭과 바로가기문서·사진·동영상 탭, 업무 바로가기
  6. 결과 다루기열기, 미리보기, 변환, 즐겨찾기, 태그
  7. 단축키키보드만으로 찾고 열기
  8. 공유폴더 추가NAS·UNC 경로, 외장 디스크
  9. HWP·DRM 문서본문 검색과 보안 문서의 한계
  10. 업데이트새 버전 받기
  11. 문제 해결결과가 없거나 느릴 때
  12. 문의오류 신고와 기능 제안

설치

Windows

  1. 다운로드 페이지에서 Windows 설치파일(Dawith-Search_버전_x64-setup.exe)을 받습니다. Windows 10·11 64비트용입니다.
  2. 받은 파일을 실행합니다. ‘Windows의 PC 보호’ 창이 뜨면 추가 정보 → 실행을 누릅니다. 설치파일에 코드 서명이 없어서 나오는 경고입니다.
  3. 설치가 끝나면 시작 메뉴에서 Dawith Search를 실행합니다.
더 빠르게 쓰려면 Voidtools Everything을 설치해 실행해 두세요. Dawith Search가 Everything 색인을 바로 사용해, 큰 공유폴더가 섞여 있어도 1초 안팎으로 결과를 보여 줍니다. Everything은 함께 배포하지 않으므로 따로 설치해야 합니다.

macOS

  1. Dawith.Search-1.1.8-universal.dmg를 받아 열고, 앱을 Applications 폴더로 옮깁니다. Apple Silicon과 Intel Mac 모두 지원합니다.
  2. 처음 실행할 때 경고가 나오면 Finder에서 앱을 우클릭 → 열기로 실행합니다.

macOS용 1.2.0은 준비 중입니다.

첫 실행과 검색 범위

처음 실행하면 화면 구성을 고릅니다. 버튼이 적은 간편 모드와 모든 도구가 보이는 다양한 기능 모드 중 하나를 고르면 되고, 나중에 설정 → 화면 구성에서 바꿀 수 있습니다. 검색 기능은 두 모드가 같습니다.

기본 검색 범위

Windows에서는 이 PC의 로컬 드라이브 전체를 자동으로 검색합니다. 폴더를 하나씩 지정할 필요가 없습니다. 공유폴더, 연결된 네트워크 드라이브, 외장 디스크는 직접 추가한 곳만 검색합니다.

검색 엔진

Windows에서는 쓸 수 있는 엔진을 아래 순서로 골라 자동으로 사용합니다. 따로 설정할 것은 없습니다.

  1. 실행 중인 Voidtools Everything (Everything SDK 연동)
  2. goz / gozd (NTFS 파일 목록을 읽는 오픈소스 엔진)
  3. 설치된 es.exe (Everything 명령줄 도구)
  4. Dawith Search 자체 색인

macOS에서는 단순한 이름 검색에 Spotlight를, 크기·날짜·본문·태그 조건에는 앱의 로컬 색인을 씁니다.

↑ 목차

검색 문법

Everything과 비슷한 문법을 씁니다. 이름 일부만 넣어도 되고, 필요할 때 조건을 덧붙이면 됩니다. 여러 조건은 공백으로 이어 씁니다.

문법예시뜻
공백 (AND)보고서 2026‘보고서’와 ‘2026’이 모두 들어간 항목
| (OR)jpg|png둘 중 하나라도 들어간 항목
! 또는 - (NOT)계획서 !초안‘계획서’는 포함, ‘초안’은 제외
* ? (와일드카드)*.xlsx, 회의록?.hwp*는 여러 글자, ?는 한 글자
regex:regex:^2026_정규식으로 이름 맞추기
ext:ext:hwp,pdf확장자로 제한 (쉼표나 세미콜론으로 여러 개)
size:size:>100mb크기 조건 (> < >= <=)
dm:dm:today, dm:yesterday, dm:lastweek수정한 날짜
dc:dc:today만든 날짜
content:content:계약서문서 본문 속 단어 (HWP 포함)
tag:tag:중요Dawith Search에서 붙인 태그
starred:starred:즐겨찾기한 파일
종류 바로가기doc: pic: video: audio: zip: exe: folder:문서·사진·동영상·음악·압축·실행 파일·폴더만

조합 예시

  • 예산 ext:xlsx dm:lastweek — 지난주에 고친 엑셀 중 이름에 ‘예산’이 있는 파일
  • doc: content:개인정보 !양식 — 본문에 ‘개인정보’가 있는 문서 중 이름에 ‘양식’이 없는 것
  • video: size:>1gb — 1GB보다 큰 동영상

앱 안에서도 검색 문법 도움말을 열어 예시를 볼 수 있습니다.

자연어 검색

검색창 옆 자연어 검색 버튼(다양한 기능 모드)을 켜면 평소 말투로 검색할 수 있습니다. 앱이 문장을 검색 문법으로 바꿔서 찾습니다. 명령 팔레트(Ctrl+K)에서도 켜고 끌 수 있습니다.

입력한 문장바뀌는 검색식 (예)
지난주 100GB 이상 동영상dm:lastweek size:>100gb video:
어제 작성한 엑셀 파일어제 날짜 조건 + 엑셀 확장자

인터넷이나 외부 AI를 쓰지 않고 앱 안의 규칙으로만 해석합니다. 원하는 결과가 안 나오면 자연어 검색을 끄고 검색 문법으로 직접 입력해 보세요.

필터 탭과 바로가기

필터 탭

결과 목록 위의 탭으로 종류를 좁힙니다. 탭을 누르면 해당 조건이 검색어에 더해집니다. 필터 탭, 업무 바로가기, 최근 검색, 자연어 검색 버튼은 다양한 기능 모드에서 보입니다.

탭붙는 조건
모두조건 없음
문서 · 사진 · 동영상 · 음악doc: · pic: · video: · audio:
압축 · 실행 · 폴더zip: · exe: · folder:
즐겨찾기starred:
중복dupe: (중복 파일)
결과가 너무 적다면 탭이 ‘모두’로 되어 있는지 먼저 확인하세요.

업무 바로가기

왼쪽 사이드바의 업무 바로가기는 자주 쓰는 검색을 한 번에 실행합니다. 문서 모아보기(doc:), 통계·스프레드시트(ext:xls,xlsx,csv), 한글·PDF(ext:hwp,hwpx,pdf), 오늘 수정한 파일(dm:today), 최근 7일(dm:lastweek), 즐겨찾기, 큰 파일 정리(size:>100mb)가 있습니다.

저장된 검색

자주 쓰는 검색은 현재 검색 저장으로 이름을 붙여 사이드바에 보관할 수 있습니다. 최근 검색 기록도 사이드바에서 다시 실행하거나 지울 수 있습니다.

↑ 목차

결과 다루기

결과를 고른 뒤 키보드를 쓰거나, 우클릭 메뉴에서 작업을 고릅니다.

  • 열기 — Enter 또는 더블클릭으로 기본 프로그램에서 엽니다. Ctrl+Enter는 파일이 있는 폴더를 엽니다.
  • 빠른 미리보기 — Space로 이미지·텍스트·오디오·비디오와 HWP 문서를 열지 않고 확인합니다.
  • 파일 변환 — 우클릭 → 파일 변환. PNG·JPG를 PDF로 바꾸고, PDF를 합치거나 나눕니다. Office·한글 문서의 PDF 변환은 PC에 Office, 한글 또는 LibreOffice가 있을 때만 보입니다. 원본은 그대로 둡니다. 결과 폴더에 파일을 Shift를 누른 채 끌어 놓아도 변환 메뉴가 열립니다.
  • 즐겨찾기 — 우클릭 → 즐겨찾기 토글. 즐겨찾기 탭이나 starred:로 모아 봅니다.
  • 태그 — 우클릭 → 태그 추가/관리. tag:중요처럼 태그로 검색합니다.
  • 경로 복사 · 이름 바꾸기 · 삭제 — Ctrl+C, F2, Delete. 삭제한 파일은 휴지통으로 갑니다.
  • 내보내기 — 검색 결과 목록을 CSV나 Everything EFU 파일로 저장할 수 있습니다.

공유폴더 추가

공유폴더(NAS), 연결된 네트워크 드라이브, 외장 디스크는 검색 위치로 추가해야 검색됩니다.

  1. 설정을 열고 검색 위치로 갑니다. 화면의 폴더·공유 위치 추가 버튼이나, 다양한 기능 모드의 사이드바 ‘검색 범위’ 옆 ＋를 눌러도 됩니다.
  2. 탐색기에서 고르려면 폴더·드라이브 선택을 누릅니다.
  3. 경로를 알고 있으면 공유폴더 경로 입력을 누르고 \\서버\공유폴더를 입력한 뒤 연결 확인 및 추가를 누릅니다. 접속이 되는지 먼저 확인하고 추가합니다.

추가한 위치마다 열기와 제거 버튼이 있습니다. 공유폴더에 새 파일이 생겼는데 안 보이면 추가한 위치 다시 읽기를 누르세요.

알아 둘 점

  • 공유폴더 권한이 있는 Windows 계정으로 앱을 실행해야 합니다.
  • 네트워크 드라이브(Z: 등)보다 \\서버\공유폴더 경로를 권장합니다. 관리자 권한으로 실행한 앱과 일반 앱은 드라이브 연결이 다를 수 있기 때문입니다.
  • 검색을 빠르게 유지하려고 공유폴더 결과의 크기·날짜는 ‘—’로 표시합니다. size:, dm: 필터는 공유폴더에서도 동작하지만 몇 초 걸릴 수 있습니다.
  • macOS에서는 Finder에서 공유폴더에 먼저 연결한 뒤 /Volumes/공유폴더 경로를 추가합니다.
↑ 목차

HWP·DRM 문서

일반 HWP 문서

Windows 1.2.0부터 HWP 본문을 검색하고 미리 볼 수 있습니다. 본문 속 단어는 content:로 찾습니다.

예: content:운영위원회 ext:hwp

보안(DRM) 문서

DRMONE 같은 문서 보안이 걸린 HWP는 본문을 읽을 수 없습니다. 제목(파일 이름)으로는 계속 검색되고, 미리보기에는 본문을 읽을 수 없다는 안내가 나옵니다. 본문까지 검색해야 한다면, 기관 규정상 허용되는 경우에 한해 한글에서 보안이 없는 사본으로 저장해 그 사본을 검색하세요.

이미지 속 글자

직인, 스캔한 서명처럼 문서에 그림으로 들어간 글자는 문자 인식(OCR)을 하지 않아 검색되지 않습니다.

↑ 목차

업데이트

Windows 1.2.1부터는 앱 안에서 업데이트합니다. 새 버전이 있으면 상단에 vX.Y.Z 업데이트 버튼이 나타납니다. 버튼을 누르면 설치파일을 받아 SHA-256 값을 확인하고, 진행 창을 보여 주며 설치한 뒤 앱을 다시 시작합니다.

1.2.0에는 자동 업데이트가 없습니다. 다운로드 페이지에서 최신 설치파일을 받아 한 번만 직접 설치하세요. 바뀐 내용은 GitHub 릴리스에서 볼 수 있습니다.

문제 해결

찾는 파일이 결과에 없을 때

  1. 필터 탭이 모두인지 확인합니다.
  2. 검색어를 줄입니다. 공백은 AND라서 단어가 많을수록 결과가 줄어듭니다.
  3. 공유폴더·외장 디스크에 있는 파일이라면 검색 위치로 추가했는지 확인합니다.
  4. 설정 → 검색 위치에서 추가한 위치 다시 읽기를 누릅니다.
  5. 본문 속 단어라면 content:를 붙입니다. 보안(DRM) 문서와 이미지 속 글자는 본문 검색이 되지 않습니다.

검색이 느릴 때

  • Windows에서는 Everything을 설치하고 실행해 두세요. 가장 효과가 큽니다.
  • 공유폴더에 size:·dm: 조건을 걸면 몇 초 걸릴 수 있습니다. 이름 조건을 먼저 넣어 범위를 줄이면 빨라집니다.

검색할 때 검은 창이 잠깐 뜰 때

1.2.0 이전 Windows 버전의 문제입니다. 1.2.0으로 업데이트하세요.

더 많은 질문은 자주 묻는 질문을 보세요.
