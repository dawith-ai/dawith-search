빠른 검색

  • rayonDawith 색인을 CPU 코어 여러 개로 나눠 검색 · MIT 또는 Apache-2.0
  • notify파일이 생기거나 지워지면 바로 색인에 반영 · CC0-1.0
  • Everything SDK선택 연결: 실행 중인 Everything에 IPC로 검색 요청(기본은 사용하지 않음) · MIT
  • goz선택 연결: NTFS MFT를 읽는 검색 엔진(goz, gozd, 기본은 사용하지 않음) · MIT

1.3.0부터 Windows 검색은 Dawith 자체 색인으로 합니다. Everything SDK 도우미와 goz는 설치본에 선택 구성 요소로 들어 있고, 설정 파일에서 직접 켠 경우에만 씁니다. Everything 본체는 Voidtools의 별도 프로그램입니다. Dawith Search에는 들어 있지 않고, 설치된 Everything.exe를 복사하지도 않습니다. Everything은 voidtools의 제품이자 상표이며, Dawith Search는 voidtools와 관계없는 별도 프로젝트입니다.

참고한 프로젝트

코드는 가져오지 않고 기능과 설계를 참고했습니다.

  • Everything AND·OR·NOT, ext:, size: 같은 검색 문법을 참고했습니다.
  • Sift File Search 저장 검색, 최근 검색, 키보드만으로 다루는 방식을 참고했습니다.
  • File-Find 검색 캐시, 제외 목록, 권한 안내를 참고했습니다.
  • FilesMate 폴더 범위, 즐겨찾기, 미리보기를 묶어 쓰는 방식을 참고했습니다.
