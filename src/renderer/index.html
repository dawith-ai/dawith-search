⚙️ Dawith Search 설정

  • Alt + Space : 어디서든 Dawith Search 즉시 호출/숨기기
  • Space : 선택한 파일 즉시 Quick Look 미리보기
  • Enter : 파일 기본 프로그램으로 실행
  • Ctrl + Enter : 파일이 있는 폴더 열기 (Explorer)
  • F2 : 이름 변경
  • Delete : 휴지통으로 파일 삭제
  • Ctrl + C : 파일 전체 경로 복사
