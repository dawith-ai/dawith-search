처음 3분 사용법

검색창에 입력하고 결과를 선택하면 됩니다. 나머지는 필요할 때 꺼내 쓰는 도구입니다.

01

검색 루트를 확인하세요

설정에서 Desktop, Documents, Downloads 같은 기본 루트를 확인하고 필요한 폴더를 추가합니다.

⚙ 설정 → 색인할 폴더
02

아는 만큼만 입력하세요

report처럼 이름 일부만 입력해도 됩니다. 자연어 모드는 인터넷이나 외부 AI 없이 규칙으로 검색식을 바꿉니다.

⌘/Ctrl + F → 검색창
03

결과에서 바로 작업하세요

Enter로 열고, Ctrl/⌘ + Enter로 위치를 열고, Space로 미리 봅니다. 우클릭에는 태그와 안전한 삭제가 있습니다.

Space → Quick Look
OFFICE WORKFLOW

기관 업무에 자주 쓰는
검색을 미리 모았습니다.

왼쪽 업무 바로가기에서 문서·통계·최근 수정 파일을 바로 열고, 자주 쓰는 검색은 “현재 검색 저장”으로 팀의 업무 흐름에 맞게 이름을 붙여 보관하세요.

▤

문서 모아보기

doc:

한글·워드·PDF·텍스트 문서를 한 번에 찾습니다.

▦

ext:xls,xlsx,csv

dm:today

SEARCH LANGUAGE

검색 문법은 짧게,
결과는 정확하게.

공백은 AND입니다. 여러 조건을 한 줄에 조합하고, 모르는 문법은 문법 도움말에서 예시를 복사해 시작하세요.

report 2026보고서와 2026을 모두 포함
jpg|pngjpg 또는 png 파일
doc !draftdoc은 포함하고 draft는 제외
ext:pdf,xlsx확장자로 제한
size:>100mb100MB보다 큰 파일
dm:today오늘 수정한 항목
regex:^2026_정규식으로 이름 매칭
content:계약서지원하는 텍스트 파일의 본문 검색
✦
규칙 기반 자연어 검색도 선택할 수 있습니다.

“지난주 100GB 이상 동영상” → dm:lastweek size:>100gb video: · 외부 AI나 서버를 사용하지 않습니다.

UNDER THE HOOD

플랫폼에 맞는 검색 엔진

백엔드는 자동 선택됩니다. 특정 기능이 필요한 쿼리는 정확도를 위해 로컬 인덱서로 전환됩니다.

⊞
WINDOWS

Everything + 공유 폴더

실행 중인 Voidtools Everything과 `es.exe`가 발견되면 네이티브 인덱스를 사용합니다. `\\\\서버\\공유폴더`를 검색 루트로 추가하면 Everything에 없는 접근 가능한 공유 폴더도 자체 색인으로 보완합니다.

DAWITH_ES_PATH=…\\es.exe
⌘
MACOS

Spotlight + 로컬 색인

단순 파일명 검색은 Spotlight로 빠르게 시작하고, 크기·날짜·본문·태그 조건은 로컬 색인에서 일관되게 처리합니다.

simple → Spotlight / advanced → local
