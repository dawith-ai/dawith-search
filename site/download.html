최근 달라진 점

  • 1.2.2 이미지→PDF, PNG↔JPG 변환과 PDF 합치기·나누기를 별도 프로그램 없이 할 수 있습니다.
  • 1.2.2 Word·Excel·PowerPoint·한글 문서를 PC에 설치된 프로그램으로 PDF로 바꿉니다. 암호나 보안(DRM)이 걸린 파일은 변환하지 않고 안내합니다.
  • 1.2.1 새 버전이 나오면 앱의 업데이트 버튼 한 번으로 설치되고 다시 실행됩니다.
  • 1.2.1 입력 중 검색 결과가 끊기거나 늦게 따라오던 문제를 고쳤습니다.
  • 1.2.0 HWP 문서의 본문까지 검색하고 미리 볼 수 있습니다.
  • DRM이 걸린 HWP는 제목으로만 검색되며, 본문을 읽을 수 없다는 안내가 표시됩니다.
  • 공유폴더(UNC) 경로를 추가·제거하는 화면을 다듬었습니다.
  • 검색할 때 검은 콘솔 창이 잠깐 뜨던 문제를 고쳤습니다.
  • 공유폴더 결과가 많을 때 검색이 느려지던 문제를 개선했습니다.
  • Everything 연동이 동작하지 않던 문제를 고쳤습니다.

설치 전에 확인하세요

  • 지원 환경 Windows 10·11 64비트, macOS(Apple Silicon·Intel)에서 동작합니다.
  • SmartScreen 경고 코드 서명 인증서가 없어 “Windows의 PC 보호” 창이 뜰 수 있습니다. 추가 정보 → 실행을 누르면 설치가 이어집니다.
  • macOS 첫 실행 Gatekeeper 경고가 나오면 Finder에서 앱을 우클릭한 뒤 열기를 선택하세요.
  • 더 빠른 검색 Everything이 설치되어 있으면 Windows에서 더 빠르게 검색합니다. 없어도 자체 색인으로 동작합니다.

SHA256

받은 파일이 손상되거나 바뀌지 않았는지 확인할 때 쓰세요. Windows에서는 PowerShell에서 Get-FileHash 파일이름, macOS에서는 터미널에서 shasum -a 256 파일이름으로 값을 볼 수 있습니다.
