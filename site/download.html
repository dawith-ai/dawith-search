최근 달라진 점

  • 1.3.22 Mac에서 Spotlight 검색을 실행하지 못했을 때 빈 결과처럼 보이던 문제를 고쳤습니다. 검색 오류를 화면에 보여 주고, 파일 이름 검색은 macOS 시스템 명령의 절대 경로로 실행합니다. 상단 바를 잡고 창을 옮길 수 있습니다.
  • 1.3.21 앱의 ‘사용 안내’ 버튼이 Everything(voidtools) 홈페이지로 연결되던 문제를 고쳤습니다. 이제 Dawith Search 도움말이 열립니다.
  • 1.3.20 경로를 누르거나 Ctrl+Enter로 폴더를 열 때, 경로에 띄어쓰기가 있으면 해당 폴더 대신 ‘문서’ 폴더가 열리던 문제를 고쳤습니다. 공유폴더도 이제 해당 파일이 선택된 채로 열립니다.
  • 1.3.19 결과의 경로를 누르면 그 폴더가 열립니다. 경로 열도 끌어서 넓힐 수 있고, 엑셀·파워포인트·한글·PDF는 색 배지로 바로 구분됩니다. 정확도가 같으면 최근 수정한 파일이 먼저 나옵니다. 본문 검색 안내창과 업데이트 안내를 읽기 쉽게 정리했습니다.
  • 1.3.18 문서 내용으로 찾는 본문 검색이 생겼습니다(선택 기능, 기본 꺼짐). 제목 표시줄의 본문 켬을 누르고 안내에 동의하면 고른 폴더의 HWP·HWPX·Word·Excel·PowerPoint·PDF·텍스트를 읽어 본문 탭에서 찾습니다. 암호·DRM 문서는 읽지 않고, 끄면 저장한 내용이 바로 지워집니다. 자세히
  • 1.3.17 오픈소스 고지를 보강했습니다. 앱에 들어간 모든 라이브러리의 라이선스 전문이 설치 폴더의 licenses 폴더에 함께 설치되고, Everything 관련 문구를 사실에 맞게 고쳤습니다.
  • 1.3.16 결과 표의 열 경계를 드래그해 너비를 바꿀 수 있습니다(더블클릭하면 내용에 맞춤). 이름 열이 기준이라 경로가 길어도 파일 이름이 잘리지 않습니다. 즐겨찾기한 파일만 별이 칠해지고, 도구 메뉴의 용량·중복 분석이 작동합니다.
  • 1.3.15 미리보기(Space)에서 사진이 깨져 보이던 문제를 고쳤습니다. Linux용 설치파일(.deb·.rpm·AppImage)도 함께 배포합니다.
  • 1.3.14 설정에서 업데이트 확인을 누르면 결과 창이 설정 창 뒤에 가려지던 문제를 고쳤습니다.
  • 1.3.13 자동으로 검색되는 드라이브(구글 드라이브, USB 등)도 설정에서 뺄 수 있고, 언제든 다시 포함할 수 있습니다.
  • 1.3.12 검색 결과의 폴더(공유폴더, 구글 드라이브 등)를 누르면 열리지 않던 문제를 고쳤습니다. 이제 탐색기로 열립니다.
  • 1.3.11 제목 표시줄 보기 옆에 설정 버튼이 생겼고, 설정은 버전·업데이트가 있는 맨 위부터 열립니다.
  • 1.3.10 설정 창 항목 사이에 여백과 구분선을 넣어 읽기 쉽게 정리했습니다.
  • 1.3.9 간편 모드가 큰 검색창과 결과만 보이는 화면으로 바뀌었고, 제목 표시줄 버전을 누르면 업데이트를 확인합니다.
  • 1.3.8 자연어 검색을 없앴습니다. 이제 입력한 글자를 바꾸지 않고 그대로 찾습니다(예: “공문서”를 치면 “공문서”가 들어간 파일).
  • 1.3.7 새 버전이 없을 때 업데이트 버튼이 보이던 문제를 고쳤고, 최신 버전이면 그렇다고 알려 줍니다.
  • 1.3.6 업데이트할 때 진행 창이 보이고, 새 버전이 있으면 빨간 점과 달라진 점을 알려 줍니다.
  • 1.3.5 결과에서 파일 이름을 한 번 누르면 바로 열립니다. 여는 동안 창이 멈추지 않습니다.
  • 1.3.4 창을 닫아도 트레이에서 파일 목록을 계속 만들고, 머리글을 눌러 정렬할 수 있습니다.
  • 1.3.0 Windows 검색이 Dawith Search 자체 색인으로 바뀌었습니다. Everything을 따로 설치하지 않아도 되고, 기본으로 쓰지 않습니다.
  • 1.3.0 처음 실행할 때 파일 목록을 만들고(C 드라이브 기준 1분 정도), 다음부터는 저장된 목록으로 바로 검색합니다. 첫 실행 안내 창과 제목 표시줄 진행 막대로 진행 상황을 보여 줍니다.
  • 1.2.2 이미지→PDF, PNG↔JPG 변환과 PDF 합치기·나누기를 별도 프로그램 없이 할 수 있습니다.
  • 1.2.2 Word·Excel·PowerPoint·한글 문서를 PC에 설치된 프로그램으로 PDF로 바꿉니다. 암호나 보안(DRM)이 걸린 파일은 변환하지 않고 안내합니다.
  • 1.2.1 새 버전이 나오면 앱의 업데이트 버튼 한 번으로 설치되고 다시 실행됩니다.
  • 1.2.1 입력 중 검색 결과가 끊기거나 늦게 따라오던 문제를 고쳤습니다.
  • 1.2.0 HWP 문서의 본문까지 검색하고 미리 볼 수 있습니다.
  • DRM이 걸린 HWP는 제목으로만 검색되며, 본문을 읽을 수 없다는 안내가 표시됩니다.
  • 공유폴더(UNC) 경로를 추가·제거하는 화면을 다듬었습니다.
  • 검색할 때 검은 콘솔 창이 잠깐 뜨던 문제를 고쳤습니다.
  • 공유폴더 결과가 많을 때 검색이 느려지던 문제를 개선했습니다.
  • Everything 연동이 동작하지 않던 문제를 고쳤습니다.

설치 전에 확인하세요

  • 지원 환경 Windows 10·11 64비트와 macOS(Apple Silicon·Intel) 설치파일을 제공합니다.
  • SmartScreen 경고 코드 서명 인증서가 없어 “Windows의 PC 보호” 창이 뜰 수 있습니다. 추가 정보 → 실행을 누르면 설치가 이어집니다.
  • Mac 설치 Mac 설치 파일은 위에서 받을 수 있습니다. 처음 실행할 때 아래 방법을 따라 하세요.
  • 첫 실행 Windows에서는 처음 실행할 때 파일 목록을 만듭니다. C 드라이브 기준 1분 정도 걸리며, 그동안에도 찾은 파일부터 검색됩니다. 다른 프로그램을 따로 설치할 필요는 없습니다.

Mac에서 처음 열기

처음 한 번만 하면 됩니다. 개발자 서명 비용 없이 배포하는 앱이라 Mac이 확인 창을 띄울 수 있습니다. 아래 순서대로 열면 됩니다.

  1. 다운로드한 파일 열기 화면 아래 파란 얼굴 모양의 Finder를 누르고 왼쪽의 다운로드를 누릅니다. Dawith.Search_1.3.22_universal.dmg 파일을 두 번 누릅니다.
  2. 응용 프로그램에 넣기 열린 창에서 Dawith Search 아이콘을 Applications(응용 프로그램) 폴더 그림 위로 끌어다 놓습니다.
  3. 처음 실행하기 Finder 왼쪽에서 응용 프로그램을 열고 Dawith Search 아이콘을 Control 키를 누른 채 클릭한 다음, 메뉴에서 열기를 누릅니다.
  4. 확인 창에서 열기 “인터넷에서 다운로드한 앱” 안내가 나오면 열기를 누릅니다. 열기 버튼이 없으면 완료를 누르고, 시스템 설정 → 개인정보 보호 및 보안에서 Dawith Search 옆의 열기를 누릅니다.
  5. 다음부터 응용 프로그램 폴더에서 Dawith Search를 두 번 누르면 열립니다.

이 방법은 Mac마다 한 번만 하면 됩니다. “컴퓨터를 손상시킵니다” 또는 “앱이 손상되었습니다”라고 나오면 실행을 멈추고 문의해 주세요. Mac용 앱은 Apple의 개발자 서명·공증을 거치지 않은 무료 배포본입니다.

SHA256

받은 파일이 손상되거나 바뀌지 않았는지 확인할 때 쓰세요. Windows에서는 PowerShell에서 Get-FileHash 파일이름, macOS에서는 터미널에서 shasum -a 256 파일이름으로 값을 볼 수 있습니다.
