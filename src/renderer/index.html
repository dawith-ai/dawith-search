    구조·증거 분석

    파일 목록, SHA-256 식별자, 정적 import 관계와 Electron 경계를 이 PC 안에서만 확인합니다. 실행 여부와 동적 코드는 미확인으로 남깁니다.

    검색 폴더를 선택하고 분석을 시작하세요.

    ⚙️ Dawith Search 설정

    -새 버전이 나오면 오른쪽 위 업데이트 버튼에 빨간 점이 표시됩니다.

    버튼이 많아 복잡하게 느껴지면 간편 모드를 선택하세요. 검색 기능은 동일합니다.

    Windows NTFS에서는 포함된 오픈소스 `goz` 엔진을 우선 사용합니다. 최초 한 번만 관리자 권한으로 서비스를 설치하면 로컬 드라이브 파일명을 빠르게 색인하고 변경사항을 추적합니다.

    백엔드 확인 중

    공유폴더는 Windows 계정 권한으로 별도 검색 경로에 추가합니다. macOS에서는 Spotlight/로컬 색인을 사용합니다.

    내 PC의 드라이브는 자동으로 검색합니다. 검색하지 않을 드라이브(예: 구글 드라이브, USB)는 제거로 뺄 수 있고, 공유폴더·다른 위치는 아래에서 추가합니다.

    현재 검색 위치 0곳

    Windows 공유폴더는 현재 Windows 계정의 접근 권한으로 확인합니다. macOS는 Finder에서 연결한 뒤 /Volumes 경로를 사용하세요.
