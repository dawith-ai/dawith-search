설치할 때 파란 경고 창이 뜨면

Windows에서 설치파일을 열면 ‘Windows의 PC 보호’ 창이 뜰 수 있습니다. 무료로 배포하는 프로그램이라 유료 코드 서명 인증서가 없어서 나오는 안내이고, 아래 순서로 설치하면 됩니다.

  1. Windows의 PC 보호

    Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

    추가 정보 실행 안 함

    1. 추가 정보를 누릅니다.
    창 왼쪽 위, 글자 아래의 밑줄 친 링크입니다.

  2. Windows의 PC 보호

    앱: Dawith-Search_x64-setup.exe
    게시자: 알 수 없는 게시자

    실행실행 안 함

    2. 실행을 누릅니다.
    ‘실행 안 함’ 왼쪽에 새로 생긴 버튼입니다.

  3. Dawith Search 설치

    파일을 설치하는 중입니다…

    3. 설치가 이어집니다.
    끝나면 Dawith Search가 자동으로 열립니다.

이 사이트나 GitHub 릴리스에서 받은 파일만 이렇게 실행하세요. 받은 파일이 원본인지는 아래 SHA256 값으로 확인할 수 있습니다.

최근 달라진 점

  • 1.3.15 미리보기(Space)에서 사진이 깨져 보이던 문제를 고쳤습니다. Linux용 설치파일(.deb·.rpm·AppImage)도 함께 배포합니다.
  • 1.3.14 설정에서 업데이트 확인을 누르면 결과 창이 설정 창 뒤에 가려지던 문제를 고쳤습니다.
  • 1.3.13 자동으로 검색되는 드라이브(구글 드라이브, USB 등)도 설정에서 뺄 수 있고, 언제든 다시 포함할 수 있습니다.
  • 1.3.12 검색 결과의 폴더(공유폴더, 구글 드라이브 등)를 누르면 열리지 않던 문제를 고쳤습니다. 이제 탐색기로 열립니다.
  • 1.3.11 제목 표시줄 보기 옆에 설정 버튼이 생겼고, 설정은 버전·업데이트가 있는 맨 위부터 열립니다.
  • 1.3.10 설정 창 항목 사이에 여백과 구분선을 넣어 읽기 쉽게 정리했습니다.
  • 1.3.9 간편 모드가 큰 검색창과 결과만 보이는 화면으로 바뀌었고, 제목 표시줄 버전을 누르면 업데이트를 확인합니다.
  • 1.3.8 자연어 검색을 없앴습니다. 이제 입력한 글자를 바꾸지 않고 그대로 찾습니다(예: “공문서”를 치면 “공문서”가 들어간 파일).
  • 1.3.7 새 버전이 없을 때 업데이트 버튼이 보이던 문제를 고쳤고, 최신 버전이면 그렇다고 알려 줍니다.
  • 1.3.6 업데이트할 때 진행 창이 보이고, 새 버전이 있으면 빨간 점과 달라진 점을 알려 줍니다.
  • 1.3.5 결과에서 파일 이름을 한 번 누르면 바로 열립니다. 여는 동안 창이 멈추지 않습니다.
  • 1.3.4 창을 닫아도 트레이에서 파일 목록을 계속 만들고, 머리글을 눌러 정렬할 수 있습니다.
  • 1.3.0 Windows 검색이 Dawith Search 자체 색인으로 바뀌었습니다. Everything을 따로 설치하지 않아도 되고, 기본으로 쓰지 않습니다.
  • 1.3.0 처음 실행할 때 파일 목록을 만들고(C 드라이브 기준 1분 정도), 다음부터는 저장된 목록으로 바로 검색합니다. 첫 실행 안내 창과 제목 표시줄 진행 막대로 진행 상황을 보여 줍니다.
  • 1.2.2 이미지→PDF, PNG↔JPG 변환과 PDF 합치기·나누기를 별도 프로그램 없이 할 수 있습니다.
  • 1.2.2 Word·Excel·PowerPoint·한글 문서를 PC에 설치된 프로그램으로 PDF로 바꿉니다. 암호나 보안(DRM)이 걸린 파일은 변환하지 않고 안내합니다.
  • 1.2.1 새 버전이 나오면 앱의 업데이트 버튼 한 번으로 설치되고 다시 실행됩니다.
  • 1.2.1 입력 중 검색 결과가 끊기거나 늦게 따라오던 문제를 고쳤습니다.
  • 1.2.0 HWP 문서의 본문까지 검색하고 미리 볼 수 있습니다.
  • DRM이 걸린 HWP는 제목으로만 검색되며, 본문을 읽을 수 없다는 안내가 표시됩니다.
  • 공유폴더(UNC) 경로를 추가·제거하는 화면을 다듬었습니다.
  • 검색할 때 검은 콘솔 창이 잠깐 뜨던 문제를 고쳤습니다.
  • 공유폴더 결과가 많을 때 검색이 느려지던 문제를 개선했습니다.
  • Everything 연동이 동작하지 않던 문제를 고쳤습니다.

설치 전에 확인하세요

  • 지원 환경 Windows 10·11 64비트, macOS(Apple Silicon·Intel)에서 동작합니다.
  • SmartScreen 경고 코드 서명 인증서가 없어 “Windows의 PC 보호” 창이 뜰 수 있습니다. 추가 정보 → 실행을 누르면 설치가 이어집니다.
  • macOS 첫 실행 Gatekeeper 경고가 나오면 Finder에서 앱을 우클릭한 뒤 열기를 선택하세요.
  • 첫 실행 Windows에서는 처음 실행할 때 파일 목록을 만듭니다. C 드라이브 기준 1분 정도 걸리며, 그동안에도 찾은 파일부터 검색됩니다. 다른 프로그램을 따로 설치할 필요는 없습니다.
