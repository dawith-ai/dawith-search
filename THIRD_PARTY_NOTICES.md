## goz

Windows NTFS filename indexing is provided by the vendored `native/goz`
project (https://github.com/mustafaahci/goz, MIT). Its copyright and license
text are preserved in [native/goz/LICENSE](native/goz/LICENSE). Its es.exe
compatible command-line handling follows the rules of voidtools ES
(https://github.com/voidtools/ES, MIT, Copyright (c) 2025 voidtools); that
notice is kept in [native/goz/LICENSE-voidtools-ES.txt](native/goz/LICENSE-voidtools-ES.txt).

## Voidtools Everything SDK

The optional `everything-ipc.exe` helper is a small bridge built from the
Everything SDK source included under `native/everything-sdk`
(`Everything.c`, `Everything.h`, `Everything_IPC.h`; MIT, Copyright (C)
2016-2022 David Carpenter). It talks to an Everything process the user
installed separately; the Everything application, database, UI and
`Everything64.dll` are not bundled. The SDK license is preserved in
[native/everything-sdk/LICENSE](native/everything-sdk/LICENSE).

The application must not copy or redistribute the user's installed
`Everything.exe`. Since 1.3.0 the app searches its own index by default; the
SDK helper and `goz` are used only when the user sets `"useEverything": true`
in `~/.dawith-search/config.json`.

## Linux AppImage

The AppImage packs the system libraries Tauri needs to run, including
WebKitGTK, GTK, GLib and libsoup, which are licensed under the GNU LGPL 2.1 or
later (text in `licenses/LGPL-2.1.txt`). They are included unmodified, as
shipped by Ubuntu 22.04 (the CI build image), and are dynamically linked, so
they can be replaced. Their source code is available from
https://webkitgtk.org/, https://gitlab.gnome.org/GNOME and the Ubuntu source
packages (https://packages.ubuntu.com/). The .deb and .rpm packages do not
bundle them; they use the copies installed on the system.
