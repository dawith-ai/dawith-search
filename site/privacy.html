개인정보처리방침

Dawith Search는 회원 가입이 없고, 이용자의 개인정보를 수집하거나 저장하지 않습니다. 아래는 앱과 이 안내 사이트를 쓸 때 어떤 정보가 어디에서 처리되는지 정리한 내용입니다.

데이터 처리 안내 · 해외 서버 안내 · 광고·쿠키 안내 · 이용약관

1. 수집하는 개인정보

Dawith Search(앱)와 이 사이트는 이름, 연락처, 이메일, 계정 같은 개인정보를 수집하지 않습니다. 사용 통계나 오류 보고도 자동으로 보내지 않습니다.

2. 데이터 처리 안내

  • 검색과 색인 검색어, 파일 목록, 색인은 이용자의 PC 안에서만 처리합니다. 파일 내용이나 검색어를 외부로 보내지 않습니다.
  • PC에 저장되는 정보 설정, 검색 기록, 저장한 검색, 태그·즐겨찾기, 색인 캐시는 이용자 폴더의 .dawith-search에만 저장됩니다. 앱 설정에서 검색 기록을 지울 수 있고, 이 폴더를 지우면 모두 삭제됩니다.
  • 업데이트 확인 앱은 실행할 때와 10분마다 GitHub에 최신 버전이 있는지 묻습니다. 이때 GitHub 서버에는 접속 IP와 앱 식별 문구(dawith-search-updater)가 전달됩니다. 검색어나 파일 정보는 보내지 않습니다.
  • 공유폴더·Everything 공유폴더는 이용자의 Windows 계정 권한으로 직접 읽습니다. Everything은 기본으로 쓰지 않으며, 이용자가 연결을 켠 경우에도 같은 PC 안에서만 통신합니다.
  • 문의 문의는 복지 허브(welfare-hub.site) 문의 게시판이나 GitHub 이슈로 받습니다. 그곳에 남긴 내용은 각 서비스의 정책에 따라 처리됩니다.

3. 해외 서버 안내

다음 서비스는 미국에 있는 서버를 씁니다. Dawith Search가 개인정보를 넘기지는 않지만, 접속 과정에서 IP 주소 같은 접속 기록이 해당 회사에 남을 수 있습니다.

  • GitHub(GitHub, Inc.) 이 안내 사이트(GitHub Pages), 설치 파일 내려받기, 앱의 업데이트 확인. GitHub 개인정보 처리 방침
  • Vercel(Vercel Inc.) 이전 안내 사이트 주소(dawith-search-guide.vercel.app)를 열 때. Vercel 개인정보 처리 방침

4. 광고·쿠키 안내

  • 광고 앱과 사이트 모두 광고를 싣지 않습니다.
  • 쿠키·분석 도구 쿠키를 쓰지 않고, 방문 분석 도구도 쓰지 않습니다.
  • 브라우저 임시 저장 사이트는 최신 버전 정보를 GitHub에서 받아 브라우저의 세션 저장소에 10분 동안만 보관합니다. 브라우저 탭을 닫으면 지워집니다.

5. 문의와 변경

운영: Dawith AI. 개인정보 관련 문의는 문의하기로 남겨 주세요. 이 방침이 바뀌면 이 페이지에 먼저 알립니다.
